# Universal Search Fix

Perubahan pada versi ini:

- Search tampil di semua halaman: Overview, POS, Orders, Analytics, Products, Categories, Customers, Inventory, dan Settings.
- Tombol mode/tema di samping search dihapus dari topbar.
- Search dipusatkan di bagian atas dengan ukuran tetap agar tidak bergeser saat fokus.
- Mobile dan tablet memakai search di baris topbar yang sama, bukan turun ke bawah.
- Halaman POS mencari produk secara langsung.
- Products, Categories, Customers, Orders, dan Inventory menggunakan query untuk memfilter data halaman.
- Overview, Analytics, dan Settings menampilkan hasil pencarian lintas data.
- Efek focus hanya mengubah border dan shadow, tanpa mengubah lebar/posisi.
